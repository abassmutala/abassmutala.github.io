### Overview

MashHarder is an e-sports platform focused on competitive gaming, tournaments, and analytics. I contributed across multiple phases of the product, building both **consumer-facing interfaces** and **internal analytics tools** used by company staff.

### Phase 1: Web Platform UI

![Web games/tournaments page](/images/mashharder/tournament_details.jpeg)  
_A screenshot of the Web tournament details page._

#### Problem

MashHarder needed a scalable, modern frontend UI to support game listings, tournaments, and league content as the platform prepared for growth.

#### My Role

I built the **entire Phase 1 frontend UI**, translating designs into a responsive, production-ready web interface

#### What I Built

- Game, tournament, and league listing pages

- Core layout structure and navigation

- Reusable UI components for future feature expansion

#### Tech

Next.js · Tailwind CSS · TypeScript · Radix UI

### Phase 2: Mobile Application UI

![Mobile tournament screen](/images/mashharder/tournament_dark.png)  
_A screenshot of the mobile tournament screen._

#### Problem

The product required a mobile-first experience for users engaging with games, tournaments, and predictions.

#### My Role

I built the **entire mobile application UI end-to-end** using Flutter, covering all core user flows.

#### What I Built

- Complete Flutter UI from scratch

- Game, tournament, and league screens

- Bottom navigation and routing architecture

- Reusable widgets for consistent UX across screens

### Technical Stack

Flutter · Dart

### Phase 3: Internal Analytics Dashboard

![Analytics dashboard overview](/images/mashharder/analytics_dashboard.jpeg)  
_An sample overview of the analytics dashboard._

#### Problem

Company leadership needed a private dashboard to monitor platform activity, metrics, and content performance without relying on engineering support.

#### My Role

I designed and built a staff-only analytics dashboard, integrating multiple data sources.

#### What I Built

- Analytics dashboard UI for internal staff

- API integration with the backend services

- YouTube Data API integration to track channel subscriber metrics

- Role-restricted access to internal tools

#### Tech

Next.js · Tailwind CSS · REST APIs · YouTube Data API

### Key Technical Contributions

- Delivered **multiple product phases** across web, mobile, and internal tools

- Built reusable component systems to accelerate future development

- Integrated third-party APIs alongside internal backend services

- Ensured consistent UX across consumer-facing and internal applications

### Outcome / Impact

- Web and mobile UIs established the foundation for MashHarder’s consumer product

- Internal analytics dashboard enabled leadership to track metrics without manual reporting

- Work supported a platform that has since secured **$100,000 in funding**

### Notes

Some components are internal or pre-launch.
